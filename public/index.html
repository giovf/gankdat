built for ai agents, not just humans

mcp server

Point any MCP client at /mcp: tools for every dataset, deterministic JSON results, usage built in. No key yet? Every tool answers a 5-row preview without one, and the agent can sign you up itself — request_api_key emails you one approval link. Also in Claude's connectors directory (how).

x402 micropayments

No account? Agents pay per request in USDC at /x402/data/… — x402 v2, with each dataset's query schema and an output example in the 402 terms, so an agent can build the call before it pays. Zero commission.

change feeds

Every register diffs itself each morning: /v1/changes/…?since=YYYY-MM-DD returns what was added, removed or changed — food hygiene, charities, care locations, schools, NHS organisations, sponsors, exclusions, gambling licences and the weekly trade-mark journal — with the dataset's own filters, so ?classes=09&q=acme is a watch. 90-day history, MCP tool get_changes; the activity per day is on each stats page. Poll the delta, not the register — no other source publishes official-register deltas.

openapi 3.1

The whole surface is described at /openapi.json — generated from the same schemas that validate every request.
