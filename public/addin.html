gankdat for Excel

Six custom functions that put official UK and EU registers in a cell: Companies House, the Charity Commission register, the CQC care directory, the UK sanctions list, Find a Tender — and GANKDAT.QUERY for the other registers gankdat serves (schools, NHS organisations, food hygiene, visa sponsors, EU TED, US exclusions, new incorporations, insolvency, contract awards, the trade marks journal, gambling licences). Each formula is one call to the gankdat API with your own key; results spill as a header row plus data rows.

Listed free on Microsoft AppSource; the add-in itself costs nothing. A gankdat API key is free for 250 calls a month, and paid plans or one-off credit packs add more — bought on gankdat.com, never through the store ("Additional purchase may be required" on the listing says exactly this).

Install

  1. In Excel (Windows, Mac or the web), Home → Add-ins → More add-ins, search for gankdat and add it. Until the AppSource listing is live, sideload the manifest instead: manifest.xml (Excel on the web: Add-ins → More add-ins → Upload my add-in).
  2. Open the UK registers button on the Home tab. Preview any register — no key needed, five rows a call.
  3. Paste your API key from gankdat.com/account (free). The key is kept in the add-in's own storage for this Excel profile and is only ever sent to gankdat.com.

Functions

Formula Returns Register
=GANKDAT.UKCOMPANY(company, [field]) One company's record by number ("00000006") or name (top search hit): status, type, incorporation date, SIC codes, registered office, charges, filings and controller counts. With field (e.g. "status", "incorporated_on", "postal_code") a single cell. uk-company-profiles
=GANKDAT.UKCHARITY(charity, [rows]) Charities whose name contains the text, or the one with that registered number. uk-charities
=GANKDAT.CQC(search, [rows]) Regulated care locations matching a name or provider; a postcode or outward code ("SW1A") filters by postcode. uk-care-locations
=GANKDAT.SANCTIONS(name, [rows]) UK sanctions list designations whose name contains the text; no match when none. A screening aid, not legal advice. uk-sanctions
=GANKDAT.TENDERS(search, [rows]) Find a Tender notices matching the words, newest first. uk-tenders
=GANKDAT.QUERY(source, filter, value, [rows]) Any register with one filter: =GANKDAT.QUERY("uk-schools", "postcode", "OX1"). Filters are the dataset's query parameters in the API docs; "q" searches every text field. all 17

rows is 1–100 (default 10). Each formula spends one credit per recalculation of that cell, whatever the row count; Excel recalculates a volatile sheet on open, so paste values once a lookup is final.

Examples

=GANKDAT.UKCOMPANY(A2, "status")            ' one cell per company number in column A
=GANKDAT.UKCOMPANY("Marks and Spencer")      ' whole record, two rows
=GANKDAT.SANCTIONS(B2, 3)                    ' header + up to 3 hits, or "no match"
=GANKDAT.QUERY("uk-food-hygiene", "postcode", "M1", 50)

Errors

A #VALUE! with a message starting gankdat: says what happened: no key saved yet, an unknown or revoked key, the month's credits spent (top up at /account), or an unknown field or filter — the message lists the valid names. The preview in the pane is capped at 5 rows and 20 calls a day per device.

Data and privacy

Records come from the publishers' own open feeds under their licences (per-dataset table in the terms); personal data is dropped at ingest. The add-in sends gankdat.com only your formula arguments and your key; nothing is read from your workbook except the arguments you pass. Details: privacy policy. Support: gankdat.com/feedback.
