# UK Corporate Insolvency Notices (The Gazette)

The latest **corporate** insolvency notices from The Gazette, the UK's official public record: company name, notice code and type (winding-up petitions and orders, administration, creditors' voluntary liquidation, meetings of creditors…), published and updated dates and the notice URL. Refreshed daily (Open Government Licence v3).

## What people use it for
- **Credit risk and KYB** — early warning on customers and suppliers.
- **Insolvency practitioners, asset buyers, debt purchasers** — new cases by type.

## Output (one item per notice)
`notice_id, company, notice_code, notice_type, published_at, updated_at, notice_url`

Corporate notices only; personal insolvency notices (which name individuals) are never ingested. Pay per result; set **Maximum results** to control spend. Data from gankdat.com.
