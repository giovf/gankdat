# New UK Companies (Companies House)

The **most recent UK incorporations** (rolling window of the newest ~2,000 companies, refreshed daily) from the official Companies House advanced-search API: company name and number, status, type, SIC codes, incorporation date, registered-office locality, region, postcode and country, plus the Companies House URL.

## What people use it for
- **New-business lead generation** — accountants, banks, insurers, web and software vendors, by SIC code and area.
- **KYB / onboarding** checks on brand-new counterparties.

## Output (one item per company)
`company_number, company, status, company_type, incorporated_on, sic_codes, locality, region, postal_code, country, company_url`

Officer and PSC (person) data are never included; registered-office street lines are dropped. Crown copyright — attribute Companies House if you republish. Pay per result; set **Maximum results** to control spend. Data from gankdat.com.
