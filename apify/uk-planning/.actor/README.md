# UK Planning Applications (planning.data.gov.uk)

The most recent planning applications published on the official planning.data.gov.uk platform: entity id, **reference**, **local planning authority**, description, decision date, entry/start/end dates and a location point. Refreshed daily (Open Government Licence v3).

## What people use it for
- **Construction and trades lead generation** — new applications by authority or period.
- **Property research and proptech** — activity by area.

## Output (one item per application)
`entity, reference, authority, description, decision_date, entry_date, start_date, end_date, point`

No applicant or agent names — organisation/application-level fields only. Coverage is the authorities publishing to planning.data.gov.uk (not every council portal). Pay per result; set **Maximum results** to control spend. Data from gankdat.com.
